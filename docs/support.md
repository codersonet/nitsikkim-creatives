# Support

## Report an issue

Use [GitHub Issues](https://github.com/codersonet/nitsikkim-creatives/issues) to report a reproducible defect or request a site improvement. Include:

- The affected page and a short description.
- Steps to reproduce the behavior.
- Expected and actual results.
- Browser/device details and screenshots if they help explain the issue.

Avoid posting personal data, credentials, or private student information in a public issue.

## Contact page limitation

The contact page is currently a visual, client-side demo. Its submit button displays a success state, but the form does not send, store, or deliver submissions. Do not enter sensitive information or rely on it to contact staff. This interface needs an approved delivery endpoint before it can be used as a real support channel.

## Deployment help

For a failed website update, inspect the latest GitHub Actions run for the Pages deployment workflow. Confirm the change was pushed to `main` or manually start the workflow, then check the Pages environment status.
